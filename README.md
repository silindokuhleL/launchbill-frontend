# launchbill-frontend

Next.js frontend for LaunchBill, an AI-assisted SaaS subscription billing platform.

## Purpose

LaunchBill frontend provides the dashboard for account owners, billing managers, viewers, and admins to manage plans, customers, subscriptions, invoices, payments, theme settings, AI-assisted workflows, and reporting.

## Core Standards

- Next.js.
- TypeScript.
- Tailwind CSS.
- Coss UI components as the project UI standard.
- Base UI primitives only when wrapped into reusable project components.
- Lucide icons only.
- ECharts for analytics.
- Axios through a shared API client.
- Shared `types/` folder for domain and CRUD types.
- Vitest for frontend logic.
- Codex in-app Browser plugin for critical browser flows.
- 100% mobile responsive layouts.
- AI-assisted inputs and summaries where useful.
